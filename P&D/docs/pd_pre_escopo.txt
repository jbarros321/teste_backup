As modalidades a serem cadastradas são:
●​ 6.1. Empreitada Global: Nesta modalidade fornecemos serviços e materiais de forma que no pacote está
inclusa a instalação dos produtos que fornecemos, assim como testes e entrega de todos os sistemas
funcionando. Neste modelo, no momento de comprar os materiais, estes são comprados como itens de
industrialização, uma vez que nós mesmos vamos instalar para o cliente e ele recebe um sistema montado e
não um equipamento sozinho em uma caixa. (Código de emissão de nota fiscal 7.02). Neste tipo de venda a
nota fiscal emitida é de SERVIÇOS, porém o sistema deverá fazer os calculos sobre os percentuais de mão
de obra e produtos que formam o total da proposta conforme exemplo:
Total da proposta R$ 10.000,00
(Total de materiais R$ 3.500,00 + Total de serviços R$ 6.500,00) importante configurar o sistema
de forma que incida os impostos corretos para os materiais e os impostos corretos para os
serviços como por exemplo o INSS que incide apenas sobre o valor dos serviços).
OBS.: O sistema deverá verificar na tabela dos itens inseridos no orçamento com o objetivo de
separar os itens materiais dos itens serviços para encontrar o percentual de cada um dos dois
sobre o total.

●​ 6.2. Serviços de eletricidade: Nesta modalidade não contempla materiais, sendo que caso tenha materiais
a serem instalados, o cliente é quem fornece. Este tipo de fornecimento também chamamos de H.H em
alguns casos e o que define isto, é quando o cliente não sabe o tamanho do trabalho, ou não sabe mensurar
quantos dias ele precisa para fazer todo o trabalho que precisa então ele paga por horas. (Código de
emissão de nota fiscal 7.02). Emissão de nota fiscal de SERVIÇOS.

adicional de 10% do IRPJ só é cobrado se a base de cálculo exceder R$ 60.000,00 ao trimestre, tanto
para as prestações de serviços quando para comercio/indústria.

1. Módulo de Cadastros e Configurações
1.2. Cadastro de Cargos e Precificação de Mão de Obra
O sistema deverá ter uma nova tela de cadastro para "Cargos". Para cada cargo cadastrado, será
necessário definir:
●​ Nome do Cargo: (Ex: Engenheiro, Eletricista, Programador).
●​ Unidade padrão
●​ Unidades alternativas: (Mesma lógica de conversão utilizada para produto porém dentro dos cargos que
serão utilizados para compor um serviço).
●​ Níveis e Precificação: Possibilidade de criar múltiplos níveis para cada cargo, com um valor/Hora
específico para cada um.
○​ Nível: Júnior (JR) -> Valor/Hora: R$ XX,XX
○​ Nível: Pleno (PL) -> Valor/Hora: R$ YY,YY
○​ Nível: Sênior (SR) -> Valor/Hora: R$ ZZ,ZZ
Este cadastro servirá como base para a precificação automática dos serviços nos orçamentos.
2. Orçamento
O fluxo de criação de um novo orçamento seguirá as seguintes etapas:
2.1. Início do Orçamento
1.​ Seleção da Modalidade: O usuário inicia um novo orçamento selecionando obrigatoriamente uma das 6
"Modalidades de Venda" cadastradas (Ver itens do 6.1 ao 6.6). A seleção desta modalidade definirá a base
de cálculo de impostos para o orçamento inteiro. (Ver tabela individual de cada um dos itens 6.1 ao 6.6)
2.​ Descrição do Serviço: O usuário preencherá um campo de texto livre para nomear o serviço principal do
orçamento (Ex: "Revitalização de Sala de Reunião da Diretoria").
2.2. Adição de Itens ao Orçamento
O usuário poderá adicionar dois tipos de itens ao orçamento: Serviços (Mão de Obra) e Produtos.
A) Lançamento de Serviços (Mão de Obra):
1.​ O usuário seleciona um Cargo e um Nível (Ex: Engenheiro - SR) a partir dos cadastros existentes.
2.​ O campo "Valor/diária" é preenchido automaticamente pelo sistema com o preço definido no cadastro do
cargo/nível.
3.​ O usuário informa a quantidade de dias previstos para aquele cargo na execução do serviço.
4.​ O sistema calcula o subtotal da linha: Subtotal do Serviço = Valor/diária x Quantidade de diárias.
B) Lançamento de Produtos:

Total de Serviços: Soma de todos os subtotais de mão de obra.
Total de Produtos: Soma de todos os subtotais de produtos.
Subtotal Geral: (Total de Serviços + Total de Produtos).
Impostos: Valor total dos impostos, calculado com base nas alíquotas vinculadas à Modalidade de Venda
selecionada no início do orçamento.
●​ Valor Total do Orçamento: (Subtotal Geral + Impostos).
3. Faturamento (Pedido de Venda)
3.1. Conversão de Orçamento em Pedido de Venda
Após a aprovação do cliente, o usuário deverá ter a funcionalidade de converter o orçamento em um Pedido
de Venda com um único clique.
3.2. Regras de Faturamento e Consolidação
No momento da conversão, o sistema aplicará as seguintes regras para a geração do Pedido de Venda:
1.​ Consolidação de Serviços: Todos os itens de serviço (mão de obra, cargos, horas) listados no orçamento
e levados para o Pedido de venda quando faturados serão agrupados e representados como um único item
na Nota de venda. Obs: a Baixa do estoque deverá ocorrer no momento da confirmação do pedido de
venda e não na nota.
○​ Exemplo: Descrição: "Prestação de Serviços de Mão de Obra" | Valor Total: R$ 5.914,00
2.​ Manutenção dos Produtos: Todos os itens de produto listados no orçamento serão transferidos para o
Pedido de Venda exatamente como estão.
3.​ Composição para Nota Fiscal: O sistema deverá apresentar campos para que o usuário informe, no item
de serviço consolidado, apenas informativo para que saia na descrição da observação da nota a
composição percentual do valor que corresponde a mão de obra e a material (quando aplicável, como na
Empreitada Global). OBS.: Desenvolver o sistema de forma que o percentual do orçamento seja
mostrado no pedido de venda e na emissão da nota fiscal. Este processo de mostrar os percentuais
deverá vigorar apenas para o item 6.1. EMPREITADA GLOBAL. Para os demais NÃO É NECESSÁRIO.
○​ Exemplo prático:
■​ Item no Pedido de Venda: 1 - Prestação de Serviços por empreitada global - R$ 10.000,00
■​ Campos Adicionais para Nota:
■​ % Mão de Obra: [ 60 ] % ou valor
■​ % Material: [ 40 ] % ou valor
