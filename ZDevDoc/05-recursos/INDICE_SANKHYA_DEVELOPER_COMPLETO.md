## 🎯 **Casos de Uso Práticos**

### **1. Sistema de E-commerce**
```javascript
// Integração completa de e-commerce
const api = new SankhyaAPI('https://api.sankhya.com.br', token);

// Criar cliente
const cliente = await api.criarCliente({
    nome: 'Cliente E-commerce',
    email: 'cliente@ecommerce.com'
});

// Criar pedido
const pedido = await api.criarPedido({
    cliente: cliente.id,
    itens: [
        { produto: 123, quantidade: 2, preco: 100.00 }
    ]
});
```

### **2. Sistema de Faturamento**
```python
# Integração de faturamento
api = SankhyaAPI('https://api.sankhya.com.br', token)

# Obter pedidos pendentes
pedidos = api.get_pedidos({'status': 'PENDENTE'})

# Faturar pedidos
for pedido in pedidos:
    api.faturar_pedido(pedido['id'])
```

### **3. Sistema de Relatórios**
```java
// Integração para relatórios
SankhyaAPI api = new SankhyaAPI("https://api.sankhya.com.br", token);

// Obter dados financeiros
List<Map<String, Object>> financeiros = api.getFinanceiros(
    Map.of("dataInicio", "2024-01-01", "dataFim", "2024-12-31")
);

// Gerar relatório
gerarRelatorio(financeiros);
```

### **4. Dashboard Personalizado**
```jsp
<!-- Dashboard de vendas -->
<snk:query var="vendas">
    SELECT 
        TO_CHAR(DTMOV, 'MM/YYYY') AS MES,
        SUM(VLRNOTA) AS TOTAL_VENDAS
    FROM TGFCAB
    WHERE STATUSNOTA = 'L'
    GROUP BY TO_CHAR(DTMOV, 'MM/YYYY')
    ORDER BY MES
</snk:query>

<div class="dashboard-vendas">
    <h2>Dashboard de Vendas</h2>
    <canvas id="graficoVendas"></canvas>
</div>
```
