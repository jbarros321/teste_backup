## ❓ **FAQ (Perguntas Frequentes)**

### **1. FAQ Geral**

#### **Configuração e Instalação**
**Q: Como instalar o Sankhya?**
A: A instalação do Sankhya segue um processo padronizado que inclui verificação de requisitos, download dos arquivos, configuração do banco de dados e setup inicial. Consulte o guia de instalação em [https://ajuda.sankhya.com.br/faq/instalacao](https://ajuda.sankhya.com.br/faq/instalacao).

**Q: Quais são os requisitos mínimos do sistema?**
A: Os requisitos incluem sistema operacional Windows Server 2016+, 8GB RAM mínimo, 100GB espaço em disco, e banco de dados Oracle 12c+ ou SQL Server 2016+. Detalhes completos em [https://ajuda.sankhya.com.br/faq/requisitos](https://ajuda.sankhya.com.br/faq/requisitos).

**Q: Como fazer backup do sistema?**
A: O Sankhya oferece ferramentas automáticas de backup que podem ser configuradas para execução diária, semanal ou mensal. Configure em Configurações > Backup. Mais informações em [https://ajuda.sankhya.com.br/faq/backup](https://ajuda.sankhya.com.br/faq/backup).

#### **Licenciamento e Ativação**
**Q: Como ativar minha licença?**
A: A ativação é feita através do portal de licenciamento Sankhya. Acesse [https://licenciamento.sankhya.com.br/](https://licenciamento.sankhya.com.br/) e siga o processo de ativação. Guia completo em [https://ajuda.sankhya.com.br/faq/licenciamento](https://ajuda.sankhya.com.br/faq/licenciamento).

**Q: Posso transferir minha licença para outro servidor?**
A: Sim, mas é necessário desativar a licença no servidor atual antes de ativá-la no novo servidor. Processo detalhado em [https://ajuda.sankhya.com.br/faq/transferencia-licenca](https://ajuda.sankhya.com.br/faq/transferencia-licenca).

### **2. FAQ Técnico**

#### **Desenvolvimento e Personalização**
**Q: Como criar um campo personalizado?**
A: Use o Dicionário de Dados para criar campos personalizados. Acesse Configurações > Dicionário de Dados > Tabelas > Adicionar Campo. Tutorial completo em [https://ajuda.sankhya.com.br/faq/campo-personalizado](https://ajuda.sankhya.com.br/faq/campo-personalizado).

**Q: Como implementar validações customizadas?**
A: Validações podem ser implementadas através de Eventos Programados, Botões de Ação ou validações no Dicionário de Dados. Exemplos práticos em [https://ajuda.sankhya.com.br/faq/validacoes](https://ajuda.sankhya.com.br/faq/validacoes).

**Q: Como integrar com APIs externas?**
A: Use a API de Integração Sankhya ou implemente integrações customizadas com Java. Documentação completa em [https://ajuda.sankhya.com.br/faq/integracao-apis](https://ajuda.sankhya.com.br/faq/integracao-apis).

#### **Performance e Otimização**
**Q: Como otimizar consultas lentas?**
A: Use ferramentas de análise de performance, crie índices adequados e otimize consultas SQL. Guia de otimização em [https://ajuda.sankhya.com.br/faq/otimizacao-consultas](https://ajuda.sankhya.com.br/faq/otimizacao-consultas).

**Q: Como monitorar performance do sistema?**
A: Use as ferramentas de monitoramento integradas e configure alertas de performance. Configuração em [https://ajuda.sankhya.com.br/faq/monitoramento](https://ajuda.sankhya.com.br/faq/monitoramento).

### **3. FAQ de Suporte**

#### **Canais de Atendimento**
**Q: Como entrar em contato com o suporte?**
A: Use o chat online, abra um ticket no portal de suporte ou ligue para o suporte telefônico. Canais disponíveis em [https://ajuda.sankhya.com.br/suporte/contato](https://ajuda.sankhya.com.br/suporte/contato).

**Q: Qual o tempo de resposta do suporte?**
A: O tempo varia conforme o nível de suporte contratado. Básico: 24h, Premium: 8h, Enterprise: 4h, 24/7: 2h. Detalhes em [https://ajuda.sankhya.com.br/suporte/sla](https://ajuda.sankhya.com.br/suporte/sla).

**Q: Como escalar um chamado?**
A: Use o portal de suporte para solicitar escalação ou entre em contato com seu gerente de conta. Processo em [https://ajuda.sankhya.com.br/suporte/escalacao](https://ajuda.sankhya.com.br/suporte/escalacao).
