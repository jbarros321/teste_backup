# 📚 Dicionário de Dados Sankhya - Guia Completo

## 🎯 Visão Geral

O Dicionário de Dados é uma ferramenta fundamental da plataforma Sankhya que permite a criação, gerenciamento e manipulação de estruturas de dados personalizadas. É a base para a maioria das personalizações e customizações da plataforma.

## 🏗️ Arquitetura do Dicionário de Dados

### **Componentes Principais**
- **Entidades**: Tabelas de dados
- **Campos**: Colunas das tabelas
- **Relacionamentos**: Conexões entre entidades
- **Índices**: Otimização de consultas
- **Constraints**: Validações e regras
- **Triggers**: Automações de dados

## 📊 Tipos de Dados Suportados

### **Tipos Básicos**
- **VARCHAR2**: Texto variável
- **NUMBER**: Números inteiros e decimais
- **DATE**: Datas e timestamps
- **CLOB**: Texto longo
- **BLOB**: Dados binários
- **CHAR**: Texto fixo

### **Tipos Especiais**
- **BOOLEAN**: Verdadeiro/Falso
- **CURRENCY**: Valores monetários
- **PERCENTAGE**: Percentuais
- **EMAIL**: Endereços de email
- **URL**: Links web
- **PHONE**: Números de telefone

### **Tipos de Referência**
- **ENTITY**: Referência a outras entidades
- **USER**: Referência a usuários
- **COMPANY**: Referência a empresas
- **PRODUCT**: Referência a produtos
- **PARTNER**: Referência a parceiros
