# DOCUMENTACAO DO PROJETO BRASSOL

Esta pasta contem a documentacao completa do projeto de personalizacao Brassol.

## ARQUIVOS DISPONIVEIS

### RELATORIO DE ATENDIMENTO TECNICO
- **RELATORIO_ATENDIMENTO_TECNICO.md** - Versao Markdown (fonte)
- **RELATORIO_ATENDIMENTO_TECNICO.html** - Versao HTML para visualizacao web
- **RELATORIO_ATENDIMENTO_TECNICO.pdf** - Versao PDF para impressao
- **RELATORIO_ATENDIMENTO_TECNICO.docx** - Versao Word para edicao

### DOCUMENTACAO FUNCIONAL
- **DOCUMENTACAO_FUNCIONAL_BRASSOL.md** - Versao Markdown (fonte)
- **DOCUMENTACAO_FUNCIONAL_BRASSOL.html** - Versao HTML para visualizacao web
- **DOCUMENTACAO_FUNCIONAL_BRASSOL.pdf** - Versao PDF para impressao
- **DOCUMENTACAO_FUNCIONAL_BRASSOL.docx** - Versao Word para edicao

## FORMATOS DISPONIVEIS

### MARKDOWN (.md)
- Formato fonte, facil de editar
- Compativel com GitHub, GitLab, etc.
- Codificacao ISO-8859-1

### HTML (.html)
- Visualizacao em navegadores
- Estilo GitHub Markdown aplicado
- Ideal para apresentacoes web

### PDF (.pdf)
- Formato para impressao
- Gerado via Chromium headless
- Mantem formatacao original

### DOCX (.docx)
- Formato Microsoft Word
- Editavel e compartilhavel
- Compativel com Office/LibreOffice

## COMO USAR

1. **Para visualizacao rapida**: Use os arquivos HTML
2. **Para impressao**: Use os arquivos PDF
3. **Para edicao**: Use os arquivos DOCX
4. **Para desenvolvimento**: Use os arquivos MD

## OBSERVACOES

- Todos os arquivos estao em codificacao ISO-8859-1
- Caracteres especiais foram removidos para compatibilidade
- Formato original mantido em Markdown
- PDFs gerados com Chromium headless
