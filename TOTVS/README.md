# TOTVS - Documentação de Sistemas

Documentação de referência dos principais ERPs da TOTVS utilizados na empresa.

---

## Sistemas Documentados

### [Winthor](./Winthor/)
ERP focado em **distribuição atacadista e varejo** (ex-PC Sistemas). Banco Oracle.

### [Protheus](./Protheus/)
ERP **multi-segmento** da TOTVS. Banco SQL Server/Oracle/PostgreSQL. Linguagem AdvPL/TL++.
