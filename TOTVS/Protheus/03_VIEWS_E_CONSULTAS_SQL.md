# TOTVS Protheus - Views e Consultas SQL

## Regras de Ouro para SQL no Protheus

1. **D_E_L_E_T_**: Sempre filtre `WHERE D_E_L_E_T_ = ' '` ou `<> '*'`
2. **Filial**: Considere `FILIAL` para não misturar dados de unidades
3. **Sufixo de tabela**: Nome físico = Sigla + Empresa/Filial (ex: `SA1010`, `SE1990`)
4. **Campos em branco**: Muitos campos usam espaços para "vazio", não NULL

## Consultas Práticas

### 1. Listar Clientes Ativos
```sql
SELECT A1_COD, A1_LOJA, A1_NOME, A1_NREDUZ, A1_CGC, A1_MUN, A1_EST
FROM SA1010
WHERE D_E_L_E_T_ = ' '
  AND A1_MSBLQL <> '1'  -- Não bloqueado
ORDER BY A1_NOME;
```

### 2. Pedidos de Venda com Itens
```sql
SELECT 
    SC5.C5_NUM AS PEDIDO,
    SC5.C5_EMISSAO AS EMISSAO,
    SA1.A1_NOME AS CLIENTE,
    SC6.C6_PRODUTO,
    SB1.B1_DESC AS PRODUTO,
    SC6.C6_QTDVEN AS QTD,
    SC6.C6_PRCVEN AS PRECO,
    SC6.C6_VALOR AS TOTAL_ITEM
FROM SC5010 SC5
INNER JOIN SC6010 SC6 ON SC5.C5_NUM = SC6.C6_NUM AND SC5.C5_FILIAL = SC6.C6_FILIAL
INNER JOIN SA1010 SA1 ON SC5.C5_CLIENTE = SA1.A1_COD AND SC5.C5_LOJACLI = SA1.A1_LOJA
INNER JOIN SB1010 SB1 ON SC6.C6_PRODUTO = SB1.B1_COD
WHERE SC5.D_E_L_E_T_ = ' '
  AND SC6.D_E_L_E_T_ = ' '
  AND SA1.D_E_L_E_T_ = ' '
  AND SB1.D_E_L_E_T_ = ' '
ORDER BY SC5.C5_EMISSAO DESC;
```

### 3. Títulos a Receber em Aberto
```sql
SELECT 
    E1_NUM AS TITULO,
    E1_PREFIXO,
    E1_PARCELA,
    E1_CLIENTE,
    SA1.A1_NOME AS CLIENTE_NOME,
    E1_EMISSAO,
    E1_VENCTO,
    E1_VALOR,
    E1_SALDO,
    DATEDIFF(DAY, CAST(E1_VENCTO AS DATE), GETDATE()) AS DIAS_ATRASO
FROM SE1010 SE1
LEFT JOIN SA1010 SA1 ON SE1.E1_CLIENTE = SA1.A1_COD AND SE1.E1_LOJA = SA1.A1_LOJA AND SA1.D_E_L_E_T_ = ' '
WHERE SE1.D_E_L_E_T_ = ' '
  AND SE1.E1_SALDO > 0
ORDER BY E1_VENCTO;
```

### 4. Títulos a Pagar Pendentes
```sql
SELECT 
    E2_NUM, E2_PREFIXO, E2_PARCELA,
    E2_FORNECE, SA2.A2_NOME AS FORNECEDOR,
    E2_EMISSAO, E2_VENCTO, E2_VALOR, E2_SALDO
FROM SE2010 SE2
LEFT JOIN SA2010 SA2 ON SE2.E2_FORNECE = SA2.A2_COD AND SE2.E2_LOJA = SA2.A2_LOJA AND SA2.D_E_L_E_T_ = ' '
WHERE SE2.D_E_L_E_T_ = ' '
  AND SE2.E2_SALDO > 0
ORDER BY E2_VENCTO;
```

### 5. Posição de Estoque
```sql
SELECT 
    SB2.B2_COD, SB1.B1_DESC,
    SB2.B2_LOCAL AS ARMAZEM,
    SB2.B2_QATU AS QTD_ATUAL,
    SB2.B2_QRES AS QTD_RESERVADA,
    SB2.B2_QATU - SB2.B2_QRES AS DISPONIVEL
FROM SB2010 SB2
INNER JOIN SB1010 SB1 ON SB2.B2_COD = SB1.B1_COD AND SB1.D_E_L_E_T_ = ' '
WHERE SB2.D_E_L_E_T_ = ' '
  AND SB2.B2_QATU > 0
ORDER BY SB1.B1_DESC;
```

### 6. Faturamento por Vendedor
```sql
SELECT 
    SA3.A3_COD, SA3.A3_NOME AS VENDEDOR,
    COUNT(DISTINCT SC5.C5_NUM) AS QTD_PEDIDOS,
    SUM(SC6.C6_VALOR) AS TOTAL_VENDIDO
FROM SC5010 SC5
INNER JOIN SC6010 SC6 ON SC5.C5_NUM = SC6.C6_NUM AND SC5.C5_FILIAL = SC6.C6_FILIAL AND SC6.D_E_L_E_T_ = ' '
INNER JOIN SA3010 SA3 ON SC5.C5_VEND1 = SA3.A3_COD AND SA3.D_E_L_E_T_ = ' '
WHERE SC5.D_E_L_E_T_ = ' '
  AND SC5.C5_EMISSAO >= '20260101'
GROUP BY SA3.A3_COD, SA3.A3_NOME
ORDER BY TOTAL_VENDIDO DESC;
```

## Views Sugeridas

### View de Pedidos Completa
```sql
CREATE VIEW VW_PEDIDOS_PROTHEUS AS
SELECT 
    SC5.C5_NUM, SC5.C5_EMISSAO, SC5.C5_CLIENTE, SC5.C5_LOJACLI,
    SA1.A1_NOME AS CLIENTE, SC5.C5_LIBEROK, SC5.C5_NOTA,
    SC6.C6_ITEM, SC6.C6_PRODUTO, SB1.B1_DESC AS PRODUTO,
    SC6.C6_QTDVEN, SC6.C6_PRCVEN, SC6.C6_VALOR
FROM SC5010 SC5
INNER JOIN SC6010 SC6 ON SC5.C5_NUM = SC6.C6_NUM AND SC5.C5_FILIAL = SC6.C6_FILIAL
INNER JOIN SA1010 SA1 ON SC5.C5_CLIENTE = SA1.A1_COD AND SC5.C5_LOJACLI = SA1.A1_LOJA
INNER JOIN SB1010 SB1 ON SC6.C6_PRODUTO = SB1.B1_COD
WHERE SC5.D_E_L_E_T_ = ' ' AND SC6.D_E_L_E_T_ = ' '
  AND SA1.D_E_L_E_T_ = ' ' AND SB1.D_E_L_E_T_ = ' ';
GO
```

### View de Inadimplência
```sql
CREATE VIEW VW_INADIMPLENCIA_PROTHEUS AS
SELECT 
    E1_CLIENTE, SA1.A1_NOME AS CLIENTE,
    COUNT(*) AS QTD_TITULOS,
    SUM(E1_SALDO) AS SALDO_DEVEDOR,
    MIN(E1_VENCTO) AS VENC_MAIS_ANTIGO
FROM SE1010 SE1
INNER JOIN SA1010 SA1 ON SE1.E1_CLIENTE = SA1.A1_COD AND SA1.D_E_L_E_T_ = ' '
WHERE SE1.D_E_L_E_T_ = ' '
  AND SE1.E1_SALDO > 0
  AND SE1.E1_VENCTO < FORMAT(GETDATE(), 'yyyyMMdd')
GROUP BY E1_CLIENTE, SA1.A1_NOME;
GO
```

## Dicas de Performance

| Dica | Detalhe |
|:---|:---|
| **D_E_L_E_T_** | Sempre incluir no WHERE |
| **Índices** | Consulte `SIX` para ver índices disponíveis |
| **SELECT específico** | Evite `SELECT *`, liste colunas |
| **Datas** | No Protheus, datas são VARCHAR no formato `YYYYMMDD` |
| **FILIAL** | Sempre considere nos JOINs |

> [!NOTE]
> No SQL Server, use `FORMAT(GETDATE(), 'yyyyMMdd')` para comparar com campos de data do Protheus. No Oracle, use `TO_CHAR(SYSDATE, 'YYYYMMDD')`.
