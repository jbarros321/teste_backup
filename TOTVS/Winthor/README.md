# TOTVS Winthor - Documentação

ERP focado em **distribuição atacadista e varejo**, anteriormente conhecido como PC Sistemas.

- **Banco de Dados**: Oracle
- **Prefixo de tabelas**: `PC` (ex: `PCCLIENT`, `PCPRODUT`)
- **Rotinas**: Identificadas por números (ex: 316, 336, 132)
