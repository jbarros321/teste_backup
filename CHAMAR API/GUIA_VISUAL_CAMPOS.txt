========================================
RESUMO RÁPIDO - O QUE MUDAR
========================================

✅ MUDAR:
1. Tipo de chamada: GET → POST
2. URL: Adicionar endpoint completo
3. Body: Habilitar toggle e colar JSON

✅ DEIXAR COMO ESTÁ:
1. Headers (Content-Type já está correto)
2. Variável de retorno (pode deixar padrão)

✅ CONFIGURAR DEPOIS:
1. Variáveis (depois de configurar a View)
2. Headers adicionais (só se precisar autenticação)

========================================
ORDEM DE PREENCHIMENTO RECOMENDADA
========================================

1. ✅ Primeiro: Mude GET para POST
2. ✅ Segundo: Cole a URL completa
3. ✅ Terceiro: Habilite o Body e cole o JSON
4. ✅ Quarto: Configure a View e ative Link Dinâmico
5. ✅ Quinto: Teste com o botão "Testar API"
6. ✅ Sexto: Verifique se inseriu na TGFMET
