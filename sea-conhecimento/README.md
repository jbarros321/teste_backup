# SEA — Systems Enterprise Architect · Base de Conhecimento

Coleta das páginas públicas de <https://www.searchitect.pro/> em 14/10/2026.

O SEA é um projeto independente (Paulo Chagas de Castro Filho) que expõe conhecimento especializado em Sankhya ERP para agentes de IA via MCP: um Agent Core que orquestra 24+ experts de domínio, mais uma universidade com 27 cursos.

## Estrutura

| Pasta | O que tem |
|---|---|
| `00-visao-geral/` | Página inicial: arquitetura do ecossistema, knowledge graph, proposta |
| `universidade/` | 27 cursos em 6 trilhas — ementa completa (4 módulos × 4 aulas) + 1ª aula integral |
| `experts/` | 25 fichas de especialistas: escopo, problemas típicos, limites declarados |
| `conexoes/` | 22 guias de integração MCP (Claude Code, Cursor, ChatGPT, n8n, VS Code…) |
| `_manifest.json` | Índice máquina: URL de origem, arquivo, título, tamanho |

## Limite desta coleta

Cada curso tem 16 aulas, mas sem sessão autenticada o site entrega **a ementa completa + apenas a 1ª aula na íntegra**. As 15 aulas restantes por curso exigem login (`POST /api/auth/login`); a credencial testada retornou 401. Para completar, basta uma conta válida e rodar novamente o coletor.

Conteúdo de terceiros, coletado para estudo pessoal. Avisos do autor: o SEA não é produto, suporte ou documentação oficial da Sankhya; valide qualquer recomendação em ambiente de teste antes de produção.
